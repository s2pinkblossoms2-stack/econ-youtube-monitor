# 정확도 확인표 안내 (담당자용)

앱이 키워드 언급을 얼마나 정확히 찾는지(PLAN 13번, 성공 기준 2 "정확도 95%")를 사람이 확인하는 표입니다.

## 파일

| 파일 | 누가 | 설명 |
|---|---|---|
| `확인표_금리.csv` | **담당자가 채웁니다** | 영상 24개의 링크 목록. 엑셀로 열 수 있습니다. |
| `정답표_금리.csv`, `정답표_금리.meta.json` | 열어 보지 마세요 | 앱이 어떻게 판정했는지 적힌 표입니다. 미리 보면 확인 결과가 앱 판정에 끌려갈 수 있어서 채운 뒤에 봅니다. |

## 채우는 방법

1. `확인표_금리.csv`를 엑셀로 엽니다. 글자가 깨지면 "데이터 → 텍스트/CSV 가져오기 → 파일 원본 UTF-8"로 엽니다.
2. 각 줄의 **영상 링크**를 열어 영상에서 **"금리"를 말로 했는지** 확인합니다. (자막이 아니라 실제 말 기준입니다. 영상 설명란이나 제목에만 있는 경우는 "언급안함"입니다.)
3. 오른쪽 칸에 **`언급함`** 또는 **`언급안함`** 만 적습니다. (띄어쓰기는 상관없습니다.)
4. 끝까지 보기 어려운 영상은 비워 두어도 됩니다. 비운 칸은 계산에서 빠집니다. 메모 칸은 자유롭게 씁니다.
5. 같은 이름(`확인표_금리.csv`)으로 **CSV 형식 그대로 저장**하고, 파일을 알려 주세요.

## 계산

채운 뒤 아래 명령을 실행하면 정확도가 나옵니다.

```bash
npm run check-accuracy -- 금리
```

- 표본이 24개로 작아서 나온 숫자는 오차가 큰 참고용입니다. 더 정확히 보려면 키워드를 바꾸거나 `scripts/check-sheet.ts`의 `PER_GROUP`을 늘려 다시 만들 수 있습니다.
- 다른 키워드로 만들려면 `npm run check-sheet -- 환율`처럼 실행하면 됩니다.
